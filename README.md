# agent_andre

Repositório de trabalho da missão de descoberta, definição e construção do agente do André.

## Governança

Este repositório é conduzido segundo a metodologia e governança vigentes do **MCF — Multiagent Collaboration Framework**.

Fonte de verdade metodológica: `leon337/multiagent-collaboration-framework`.

## Estado atual
